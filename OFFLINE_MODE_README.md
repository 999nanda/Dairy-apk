# NANDA Dairy & Agro — OFFLINE CURRENT VERSION

Purpose:
- Current farm-only use without a cloud server.
- Local/offline data entry and local storage.
- Designed so the same application structure can later migrate to cloud sync.

Important:
- This package does NOT require a cloud account/server.
- Data remains on the device/browser where the app is used.
- Use the built-in backup/export feature regularly.
- This ZIP is a development project, not a prebuilt APK/EXE installer.

Future migration:
- Use the separate CLOUD_READY package.
- Preserve the same business entities and field structure.
- Configure a real cloud backend and authentication before multi-device/customer use.
